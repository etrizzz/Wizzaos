# WizzaOS

WizzaOS est un projet personnel de système desktop moderne conçu pour redonner une vraie utilité à un PC x86-64 équipé de 6 Go de RAM, avec une priorité claire : travail Prismatique, web/IA, multimédia et jeux compatibles avec le matériel.

## Fondation cible

- Ubuntu 26.04 LTS (Resolute Raccoon)
- XFCE comme environnement léger et personnalisable
- architecture x86-64
- profil mémoire spécialement prévu pour 6 Go de RAM
- Steam/Proton, Wine/Lutris en option
- applications web IA et outils de production accessibles sans alourdir le démarrage

## Principe de développement

`main` reste la branche de référence. Les évolutions sont préparées sur `wizza-dev`, testées, puis proposées avant intégration dans `main`.

## État

Projet expérimental en construction. Aucun ISO stable n'est encore publié.

## Objectif

Faire de cette ancienne machine un poste utilisable au quotidien pour Prismatique : documents, navigation, IA en ligne, gestion de fichiers, traitement d'images léger, impression, communication et tâches administratives, tout en conservant la possibilité de jouer lorsque le GPU/CPU le permettent.
